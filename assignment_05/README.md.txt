# Assignment 6 - Travel Portal

This is my submission for Assignment 6. It is a full-stack web application for managing travel packages, built with Node.js and MongoDB. It includes a login page and a dashboard where an admin can add and view records.

### Technologies Used
* Node.js & Express
* MongoDB & Mongoose
* HTML, CSS, and Bootstrap 5
* EJS for templating

### Features
* Admin authentication (verifies email and password against the database).
* Dashboard to view all saved travel packages.
* Form to create new packages (saves Title, Location, Category, and Price to MongoDB).

### Output
A screenshot of the working application has been saved in the `output` folder.

### How to Run
1. Open the terminal in this assignment folder.
2. Run `npm install` to get the dependencies.
3. Make sure MongoDB is running locally.
4. Run `node app.js` to start the server.
5. Open `http://localhost:3000` in your browser.
